🌌 Репозиторий пакетов LungoOS

Официальное зеркало скомпилированных пакетов для слабого железа. Чтобы подключить его, добавьте в ваш /etc/pacman.conf:

[lungo-repo]
SigLevel = Optional TrustAll
Server = https://github.io

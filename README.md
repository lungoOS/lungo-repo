# 🌌 LungoOS Repository
Welcome to the official LungoOS package repository. Here you can find optimized builds tailored for low-end hardware.

<p>Official package mirror compiled for low-end hardware. To enable it, add the following lines to your <code>/etc/pacman.conf</code>:</p>
<pre style=background: #161b22; padding: 15px; border-radius: 6px; border: 1px solid #21262d; color: #79c0ff;>[lungo-repo]
SigLevel = Optional TrustAll
Server = https://lungoos.github.io/lungo-repo
</pre>
